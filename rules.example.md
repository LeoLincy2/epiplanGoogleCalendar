# My registration rules

Write in plain language what the agent should do. It reads this file at every /planning.
Replace the examples below with your own.

## Always propose
- Kick-offs and bootcamps of my modules.
- English support sessions when I have no class at the same time.

## Never propose
- Clubs and anything on weekends.
- Anything that overlaps a mandatory class.

## Preferences
- Slots: afternoons preferred, never before 9:00.
- At most 2 optional activities per day.

## Modules
- Warn me when a module is not registered and its window closes within 7 days.
- Modules the agent may register me to (also put them in EPIPLAN_MODULE_ALLOWLIST): none.
